# date-invite

Конструктор приглашения на свидание: собираешь экраны — получаешь ссылку, которую
получатель открывает в браузере без регистрации.

Собственная реализация механики: тексты, палитра и графика оригинальные, внешних
ассетов нет (иллюстрации — эмодзи + CSS-градиенты).

## Стек

| Слой | Технология |
|---|---|
| Сборка | Vite 7 |
| Каркас | Vue 3.5 (`script setup`) + TypeScript strict |
| Состояние | Pinia 3 |
| Роутинг | vue-router 4, hash-история |
| Хранилище | localStorage (бэкенда нет) |

## Маршруты

| Путь | Экран |
|---|---|
| `#/` | конструктор, 4 шага |
| `#/link/:id` | ссылки автора и ответ получателя |
| `#/i/:id` | приглашение из localStorage |
| `#/p/:payload` | приглашение из самой ссылки (base64url) |

## Поток получателя

1. Конверт с фото и сургучной печатью — вскрывается нажатием.
2. Вопрос: «Да» растёт, «Нет» уходит от курсора и уменьшается.
3. Подтверждение с падающими сердечками.
4. Выбор даты и времени в рамках, заданных автором.
5. Выбор активности из 3–6 карточек.
6. Финал: билет с подстановками `{date}`, `{time}`, `{activity}`.

Ответ пишется в ту же запись localStorage и виден автору на `#/link/:id`.

## Структура

```
src/
  data/        каталог активностей, картинки-заготовки, тексты-заготовки
  lib/         codec (base64url), storage, image (сжатие), range, text (подстановки)
  stores/      invitation — черновик, автосохранение, публикация
  components/
    builder/   шаги конструктора
    preview/   экраны получателя + оркестратор InvitationFlow
    ui/        поля, чипсы, рамка телефона, дождь сердечек
  views/       BuilderView, LinkView, InviteView
```

`InvitationFlow` — один компонент и для предпросмотра (`stage` задан извне,
кнопки неактивны), и для получателя (`interactive`, внутренний автомат).

## Ограничения текущей версии

- Данные живут в браузере автора: короткая ссылка `#/i/:id` работает только на том же
  устройстве. Кросс-девайсный вариант — длинная ссылка `#/p/:payload`.
- Тарифов, оплаты и водяных знаков нет — весь функционал открыт.
- Фото сжимаются до 720 px по большей стороне; при переполнении квоты localStorage
  черновик остаётся только в памяти.
- Голосового сообщения и уведомлений на почту нет (требуют бэкенда).
